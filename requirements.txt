# Environment pinned to the versions that produced every number in results/.

# These pins are not cosmetic. Re-running this pipeline under a different
# scikit-learn or xgboost release changes the estimator-dependent results. In
# one verified instance, the single-market weekly pipeline run on a
# bit-identical panel produced a tau=0.95 pinball improvement of -2.29%
# (Diebold-Mariano p = 0.026) under an earlier environment against -2.39%
# (p = 0.059) under the pinned one, moving the nominal p-value across 0.05 --
# while every data-only benchmark (B_zero, B_histmean, B_AR1) agreed to each
# printed digit, which is what identifies the estimators rather than the data
# as the source. Install these versions to reproduce results/ exactly.
#
